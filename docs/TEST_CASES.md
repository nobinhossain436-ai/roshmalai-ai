# Privacy Policy Template

Roshmalai AI keeps chart screenshots and analysis history on the user's device.

## Data stored locally
- Analysis timestamp
- Selected image URI (if the user chooses to keep it)
- Extracted observations
- User practice history, if any

## Not collected
- Broker account information
- Passwords or credentials
- Analytics or telemetry
- Screen capture from unrelated apps without explicit user action

## Deletion
Users may delete locally stored data from the app's settings screen or through the clear-history button.

## Contact / Transparency
This template should be adapted to your project and legal requirements before distribution.
