# Test Cases and Expected Results

## 1. App launches
- Expected: splash or home screen appears on a compatible Android device.

## 2. Gallery import
- Expected: user can select a valid chart screenshot from device gallery.

## 3. Invalid image
- Expected: a Bengali error message indicates that the image is not recognizable as a candlestick chart.

## 4. Offline analysis
- Expected: analysis runs with no internet connection.

## 5. Local data removal
- Expected: all saved results are deleted after the user taps the clear-data action.

## 6. Screen capture
- Expected: permission prompt appears only after the user explicitly requests capture.

## 7. Bookmarklet safety
- Expected: bookmarklet opens a panel without remote code execution.

## 8. Small-screen usability
- Expected: controls remain usable on a compact screen.
